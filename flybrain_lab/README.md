## 不夸大的“完全使用果蝇结构”定义

控制网络内部仅用上述真实有向拓扑，没有 MLP、Transformer、PPO 主干或随机补边。
神经元动力学是工程化 signed tanh rate model，**不是生物 LIF 模型复现**。
按突触数及作者兴奋/抑制符号构造矩阵，并按接收端绝对行和归一化到不超过 0.85。
神经输入端口及关节输出端口是确定性选取的工程接口，**不是已知果蝇脑区与机械臂的生物同源映射**。
输出是一个训练的线性读出，将 2048 个真实神经元状态映射为 16 关节增量。

RGB-D 投影/标定、TSDF 安全地图、已观测任务队列、接触状态机、连续轨迹证书和
紧急平滑制动仍为外围确定性工具，不能称为“每一项系统运算都是神经元实现”。
直接控制入口不得调用旧 QP/PPO/IK 产生替代动作；失败则拒绝/停止。
启动 commissioning 的已测量安全初始条件仍由外围初始化流程确定，不作为网络控制成果。

## 根据最新要求：每帧视觉及自身状态进入网络

正式探索入口为 `visual_mission.py`，旧 `mission.py` 仅为几何摘要对照。

1. 每个**控制器接收到且通过有效性检查**的相机帧进入 `VisualCircuit.ingest`。
2. 输入 RGB、depth、深度有效掩码、depth sigma、机器人自遮挡掩码、颜色有效掩码。
3. 保留原始记录；神经视网膜编码对全帧做面积重采样到 **96×54×8**。
   所有交付像素参与计算，但这是**有损压缩**，不是原分辨率逐像素无损传递。
4. 同时输入 q 的 sin/cos、由时间戳和关节记录估计的速度/加速度、上一段关节变化、
   已有模型反作用估计、K、相机外参、时间间隔/图像年龄、图像尺寸、各可用性标志。
5. 决策时另输入当前机器人 FK、测量得到的任务目标和视觉目标、阶段及持物状态。
6. 网络保留跨帧神经状态，不把每张图像独立归零处理；点云**不是神经输入必经环节**。
7. 没有图像就禁止视觉网络决策，没有偷偷降级为只看目标坐标。

限定：沿用的传感器进程是 latest-frame 传输，传输前可能丢帧；过期帧仍会被安全门禁拒绝。
`visual_input_audit.json` 记录实际神经接收情况，不能宣称覆盖相机产生的全部帧。
不存在的实物力传感器、物体真值位姿、真实物体总数和环境 CAD 不会作为输入。

## 数学形式

令 `A[j,i]` 为作者数据中 i→j 的带符号突触计数：

`W[j,i] = 0.85*A[j,i]/max(1, sum_k abs(A[j,k]))`。

每帧用固定视网膜/自身状态端口注入 `u_t`，进行四次内部更新：

`h <- 0.5*h + 0.5*tanh(W*h + u_t)`。

决策时复制 h、注入任务指令端口，再进行四次同样更新；不因重复规划查询修改视觉记忆。
`delta_q = clip(B*[normalized(h_readout);1], [-0.12×8,-0.30×8], [0.12×8,0.30×8])`。
依次尝试 1、1/2、1/4、1/8 幅度，只检查而不使用 IK 修复。
任务方向/末端姿态、RGB-D 环境、双臂几何及视觉约束全部通过后才执行 C2 平滑段。

该有界收缩动力学便于运行，但长时间空间记忆能力**尚未证实**。

## 训练与验证

首轮是监督模仿 bootstrap，不是已有神经网络权重微调：
用以前记录的编码器动作和 RGB-D 示教训练新的线性读出；网络内部连接固定。
训练场景 6101、82007，验证场景 82015；验证用于选择 ridge 系数，不能作为独立测试。
每个示教动作仅使用更早曝光的帧（初始时刻取第一帧）；所有中间帧更新状态。
网络没有读取示教控制器的内部提案作为推理输入，更没有在推理失败时调用示教控制器。
目前没有直接优化反作用损失，示教数据来自低反作用控制器，**不等于已实现反作用降低**。
必须在完成相同任务、使用可比时长的闭环运行中再比较峰值/RMS/冲量；静止不能算低冲击成功。

旧几何摘要实验 `runs/bootstrap_01` 跨场景关节 RMSE 0.0991 rad，零动作参考 0.0392 rad，
表现不佳。旧 `mission_6101_01` 停于 `no_certified_flywire_action`；
首个恢复动作仍继承了旧视觉恢复分支，故不作为纯神经控制证据。
现已在独立入口覆盖 `plan_visual_acquisition`，禁止该隐式 QP/IK 分支。
视觉回放首轮 `visual_bootstrap_01` 因 OpenCV 八通道缩放限制失败，记录保留；
逐通道面积缩放修复后运行 `visual_bootstrap_02`。

改变实际 RGB 或深度会改变最终关节输出，见 `input_ablation.json`，但不代表语义识别有效。

`visual_mission_6101_01` 中 8 个 commissioning 帧及 2 个运行接收帧全部送入神经网络。
